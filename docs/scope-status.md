# Delivery scope and research status

## Software delivered

- Next.js Radar, company research workbench, saved research and methodology.
- Pure TypeScript finance engine and independent accounting regressions.
- Formula-driven Excel model, history, evidence, bridge and sensitivity snapshots.
- Groq 20B/120B extraction adapter, verification, judge routing and content cache.
- Filing manifest fetcher, explicit-context XBRL parser and transactional Supabase writer.
- Dedicated Supabase schema with public publication gates, private review queue and owner-scoped memo policies.
- Synthetic 50-company universe in two sectors. Sample notes and incomplete-data cases are explicitly marked.

## Browser-local workflow extension

Ten additions: company comparison, named screening presets, full filtered CSV export, saved scenario library, scenario comparison, editable diligence checklists, research stages, dated next actions, printable research memos and versioned research backup/restore. Existing storage keys remain compatible. These tools do not add account sync, server writes, reminders or external data feeds. Browser printing can save a private memo as PDF; dedicated generated PDF one-pagers remain roadmap.

## Research still required before Gate 1

The software cannot truthfully perform a human's learning track, oral explanation, licensing review or independent financial labeling. These are not marked complete:

- Select a real pilot and obtain five annual reports and quarterly results with reuse permission.
- Independently build and review its LBO and all normalization references.
- Complete the 20-company human answer key and measure actual model extraction precision and recall.
- Verify official mappings and data rights for a 50-company live pilot, then widen toward 500.
- Validate leverage, interest, hurdle and tax assumptions with qualified practitioners.
- Replace demonstration memos with five real investment memos and three independently reviewed pass decisions.
- Run outreach and Gate 1/Gate 2 interviews. No messages have been sent.

## Roadmap

V2 is excluded from this v1 release: comparable-deal feeds, quarter alert infrastructure, version-to-version financial diffs, PDF one-pagers and US SEC company coverage. Scenario assumption links are implemented because they directly support reviewing a model. They never share private notes.

Database: dedicated Buyout Radar project in Mumbai, RealBhupesh's Org. Default publication contains only synthetic companies. Groq requires the user's API key, configured privately; no paid extraction run has been performed. Deployment details and verified release checks are recorded separately in the release report.
