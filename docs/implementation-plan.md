2. Define financial contracts and independent regression cases before implementing the pure engine.
3. Implement earnings normalization, cash conversion, debt capacity, five-year LBO, bridge, sensitivities and hurdle solvers.
4. Deliver a formula-driven workbook with cached results, reconciliation and provenance.
5. Implement source manifests, strict XBRL contexts/units, data quality, idempotent database writing and a deny-by-default schema.
6. Implement page finding, quoted extraction, exact amount verification, dual-model agreement, judging, review routing, cache and fixture evaluation.

8. Build Radar search, filters, Buy Box, interactive map, watchlist and company workbench with editable scenarios, source inspection, notes and exports.
9. Publish honest methodology and evaluation limitations. Supply five demonstration memos and three pass notes.
10. Verify engine/workbook parity, API boundaries, persisted state, desktop/mobile interactions, reduced motion, contrast and every design-law rule.
11. Push 100 nonempty commits, run CI and deploy to the connected Vercel team. Configure a dedicated Supabase only if requested; never modify an unrelated project.

Review focus: negative/zero EBITDA; zero-exit-equity IRR; cash shortfalls; XBRL dimensions/periods; unverified adjustments; exact quoted units/signs; formula injection in exports; malformed URL state; absent providers; storage failures.
